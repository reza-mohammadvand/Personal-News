# نبض — گلچین شخصی اخبار

یک داشبورد فارسی، سبک و موبایل‌پسند برای دنبال‌کردن ۱۸ منبع منتخب در حوزه‌های فناوری، اقتصاد، علم، فضا و نجوم. سایت کاملاً استاتیک است و GitHub Actions هر روز خوراک‌ها را جمع‌آوری و GitHub Pages را به‌روز می‌کند؛ بنابراین سرور یا دیتابیس لازم نیست. خبرها در مخزن یا آرشیو دائمی ذخیره نمی‌شوند و فایل موقت هر انتشار جای نسخه روز قبل را می‌گیرد.

## انتشار روی GitHub Pages

1. این پوشه را در یک مخزن GitHub قرار دهید و Push کنید.
2. در مخزن وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** بگذارید.
4. در تب **Actions**، گردش‌کار «بروزرسانی و انتشار اخبار» را یک بار دستی اجرا کنید.
5. پس از پایان اجرا، نشانی سایت در همان صفحه Actions و Settings → Pages دیده می‌شود.

پس از آن، خبرها روزی یک‌بار تازه می‌شوند. گزینه بازه زمانی داخل سایت به‌صورت پیش‌فرض روی ۲۴ ساعت است.

## اجرای محلی (اختیاری)

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python scripts\fetch_news.py
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای تغییر منابع و کلیدواژه‌ها، فایل `scripts/fetch_news.py` را ویرایش کنید.

> بعضی ناشران ممکن است خوراک خود را تغییر دهند، دسترسی خودکار را محدود کنند یا مطالبشان پشت دیوار پرداخت باشد. در این حالت کارت همچنان کاربر را به صفحه اصلی ناشر هدایت می‌کند و وضعیت هر منبع در خروجی اجرای Action قابل مشاهده است.
